# 🎓 คู่มือการใช้งาน Portfolio (ฉบับเข้าใจง่ายสำหรับ ม.6)

ยินดีด้วย! ตอนนี้คุณมีไฟล์โครงสร้าง Portfolio สุดเท่พร้อมใช้งานแล้ว โปรเจกต์นี้มีไฟล์หลักคือ index.html และรูปโปรไฟล์ชื่อ me.svg (หรือ me.png)

ทำตาม 4 ขั้นตอนง่าย ๆ นี้ เพื่อเปลี่ยนมันเป็นพอร์ตของคุณเองได้เลย! 👇

1. 🚀 วิธีเปิดดูผลงาน (Preview)
วิธีที่ง่ายที่สุดคือการเปิดไฟล์ในเครื่องของคุณเลย:

เข้าไปที่โฟลเดอร์โปรเจกต์

ดับเบิลคลิก ที่ไฟล์ index.html

หรือ ลากไฟล์ index.html ไปวางในหน้าเว็บเบราว์เซอร์ (Chrome, Edge, Safari)

2. ✏️ วิธีแก้ข้อมูลส่วนตัว
มาเปลี่ยนชื่อและข้อมูลให้เป็นของคุณกัน:

คลิกขวาที่ไฟล์ index.html เลือก Open with > Notepad, TextEdit หรือถ้ามี VS Code จะดีมาก

เลื่อนหาข้อความที่ต้องการแก้ (เช่น ชื่อ-นามสกุล, เกรดเฉลี่ย, ผลงาน)

แก้ข้อความ ได้เลย (ระวัง! อย่าเผลอลบเครื่องหมาย < หรือ > ที่ครอบข้อความอยู่นะ)

กดบันทึก (Save) แล้วกลับไปที่เบราว์เซอร์ กดรีเฟรช (F5 หรือ Ctrl+R) เพื่อดูผลลัพธ์

3. 🖼️ วิธีเปลี่ยนรูปโปรไฟล์
อยากโชว์หน้าตาอันหล่อเหลา/สวยงาม ทำตามนี้:

เตรียมรูปถ่ายหน้าตรงของคุณ

เปลี่ยนชื่อไฟล์รูปเป็น me.png (หรือ me.svg) ชื่อต้องเป๊ะตามนี้เท่านั้น

นำรูปไปวางทับไฟล์เดิมในโฟลเดอร์โปรเจกต์

กดรีเฟรชหน้าเว็บดูผลลัพธ์ได้เลย

หมายเหตุเรื่องไฟล์: ถ้าคุณมีไฟล์รูปนามสกุลอื่น หรืออยากใช้สคริปต์แปลงไฟล์ที่มีในโปรเจกต์ (generate_me_png.sh) สามารถทำได้ แต่แนะนำวิธีก๊อปปี้วางทับแบบข้างบนจะง่ายและชัวร์ที่สุดครับ

4. 🎨 ปรับแต่งเพิ่มเติม (ถ้าอยากทำ)
เปลี่ยนสี: มองหาคำว่า `<style>` ในไฟล์ index.html คุณสามารถลองเปลี่ยนรหัสสีได้

เมนูไม่ทำงาน: เมนูด้านบน (การศึกษา, กิจกรรม) จะทำงานอัตโนมัติเมื่อคลิก ไม่ต้องตั้งค่าอะไรเพิ่ม

❓ ปัญหาที่พบบ่อย (FAQ)
Q: รูปไม่ขึ้น ทำไงดี

A: เช็กว่าชื่อไฟล์คือ me.svg หรือ me.png เป๊ะ ๆ หรือไม่ (ระวังเรื่องตัวพิมพ์เล็ก/ใหญ่) และรูปต้องวางอยู่ ที่เดียวกับ ไฟล์ index.html

Q: แก้ภาษาไทยแล้วเป็นตัวยึกยือ

A: ตอนเซฟไฟล์ (Save As) ให้แน่ใจว่าเลือก Encoding เป็น UTF-8

✨ ต้องการความช่วยเหลือพิเศษ ถ้าอยากให้ช่วยปรับอะไรยาก ๆ เช่น ฝังรูปเข้าไปในโค้ดเลย (Inline SVG) หรือเปลี่ยนเลย์เอาต์ บอกผมได้เลย เดี๋ยวจัดให้ครับ!

สิ่งที่ปรับเปลี่ยนไปจากต้นฉบับ:
จัดกลุ่มใหม่: แยกส่วน "Advanced" (Python server) ออกมาเป็นกรอบข้อความ เพื่อไม่ให้เด็กที่ไม่ใช่สายคอมฯ รู้สึกกลัวตั้งแต่ข้อแรก

เพิ่ม Emoji: ช่วยให้ดูเป็นมิตรและแบ่งสัดส่วนสายตาได้ง่ายขึ้น
