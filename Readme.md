# 🎓 Portfolio Template (ฉบับเข้าใจง่ายสำหรับ ม.6)

ยินดีด้วย! ตอนนี้คุณมีไฟล์โครงสร้าง Portfolio สุดเท่พร้อมใช้งานแล้ว 🥳
โปรเจกต์นี้มีไฟล์หลักแค่ 2 ไฟล์ คือ `index.html` และรูปโปรไฟล์ `me.svg` (หรือ `me.png`)

---

## 🛠️ วิธีทำ: 4 ขั้นตอนง่ายๆ เปลี่ยนเป็นพอร์ตของคุณเอง

### 1. 🚀 วิธีเปิดดูผลงาน (Preview)
วิธีที่ง่ายที่สุดคือการเปิดไฟล์ในเครื่องของคุณเลย:
1. เข้าไปที่โฟลเดอร์โปรเจกต์
2. **ดับเบิลคลิก** ที่ไฟล์ `index.html`
3. หรือ **ลากไฟล์** `index.html` ไปวางในหน้าเว็บเบราว์เซอร์ (Chrome, Edge, Safari)

### 2. ✏️ วิธีแก้ข้อมูลส่วนตัว
มาเปลี่ยนชื่อและข้อมูลให้เป็นของคุณกัน:
1. คลิกขวาที่ไฟล์ `index.html` เลือก **Open with** > **Notepad**, **TextEdit** (หรือถ้ามี VS Code จะดีมาก)
2. เลื่อนหาข้อความที่ต้องการแก้ (เช่น ชื่อ-นามสกุล, เกรดเฉลี่ย, ผลงาน)
3. **แก้ข้อความได้เลย** > ⚠️ **คำเตือน:** ระวังอย่าเผลอลบเครื่องหมาย `<` หรือ `>` ที่ครอบข้อความอยู่นะครับ
4. กด **Save** แล้วกลับไปที่เบราว์เซอร์ กดรีเฟรช (**F5** หรือ **Ctrl+R**) เพื่อดูผลลัพธ์

### 3. 🖼️ วิธีเปลี่ยนรูปโปรไฟล์
อยากโชว์หน้าตาอันหล่อเหลา/สวยงาม ทำตามนี้:
1. เตรียมรูปถ่ายหน้าตรงของคุณ
2. เปลี่ยนชื่อไฟล์รูปเป็น `me.png` (หรือ `me.svg`) **ชื่อต้องเป๊ะตามนี้เท่านั้น**
3. นำรูปไปวาง **ทับไฟล์เดิม** ในโฟลเดอร์โปรเจกต์
4. กดรีเฟรชหน้าเว็บดูผลลัพธ์ได้เลย

> **Tips:** ถ้าอยากแปลงรูปเป็น .svg เพื่อความคมชัด [คลิกที่นี่](https://www.freeconvert.com/png-to-svg)

### 4. 🎨 ปรับแต่งเพิ่มเติม (ถ้าอยากทำ)
* **เปลี่ยนสี:** มองหาคำว่า `<style>` ในไฟล์ `index.html` คุณสามารถลองเปลี่ยนรหัสสีได้
* **เมนู:** เมนูด้านบน (การศึกษา, กิจกรรม) จะทำงานอัตโนมัติเมื่อคลิก ไม่ต้องตั้งค่าอะไรเพิ่ม

## ❓ ปัญหาที่พบบ่อย (FAQ)

**Q: รูปไม่ขึ้น ทำไงดี**
> A: เช็กว่าชื่อไฟล์คือ `me.svg` หรือ `me.png` เป๊ะๆ หรือไม่ (ระวังเรื่องตัวพิมพ์เล็ก/ใหญ่) และรูปต้องวางอยู่ **ที่เดียวกับ** ไฟล์ `index.html`

**Q: แก้ภาษาไทยแล้วเป็นตัวยึกยือ อ่านไม่ออก**
> A: ตอนเซฟไฟล์ (**Save As**) ให้แน่ใจว่าเลือก **Encoding** เป็น `UTF-8`

**Q: อยากให้ช่วยปรับอะไรยากๆ**
> A: เช่น ฝังรูปเข้าไปในโค้ดเลย (Inline SVG) หรือเปลี่ยนเลย์เอาต์ บอกผมได้เลย เดี๋ยวจัดให้ครับ! ✨
